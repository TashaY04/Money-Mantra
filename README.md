# 📖 Overview

Money Mantra is a full-stack personal finance management platform designed to help users monitor expenses, manage monthly budgets, and understand spending behavior through interactive financial reports.

Built using **Python, Flask, PostgreSQL, SQLAlchemy, and Jinja2**, the application provides a secure and responsive experience with authentication, real-time expense tracking, budget monitoring, and detailed financial analytics. The platform is cloud deployed on **Render** and is accessible from desktop, Android, and iOS web browsers without requiring installation.

---

# 🚀 Why Money Mantra?

Managing personal finances often involves scattered records and limited visibility into spending habits.

Money Mantra simplifies financial planning by offering:

- 💰 Smart expense tracking
- 📊 Budget planning & monitoring
- 📈 Spending analytics
- 🔐 Secure user authentication
- ☁️ Cloud deployment
- 📱 Responsive experience across desktop, Android & iOS
- 📑 Financial reports for better decision-making

# 🚀 Getting Started

```bash
git clone https://github.com/TashaY04/Money-Mantra.git

cd Money-Mantra

python -m venv venv

source venv/bin/activate

pip install -r requirements.txt

python app.py
```

The application will be available at:

```
http://localhost:5000
```
